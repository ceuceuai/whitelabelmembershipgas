Whitelabel Membership • Installation Guide

Dari Copy Google Sheets sampai Frontend Live

Ikuti urutan ini untuk memasang Whitelabel Membership GAS Client: salin file dari Member Area, jalankan menu Whitelabel System, deploy Web App, lalu pasang URL hasil deploy ke index.html dan checkout.html.

1. Salin File 2. Whitelabel System 3. Deploy GAS 4. Copy Web App URL 5. Edit Frontend 6. Live
Yang Harus Anda Lihat di Google Sheets Pastikan file sudah menjadi salinan milik Anda dan menu Whitelabel System muncul di toolbar.
Langkah Instalasi

Ikuti dari Atas ke Bawah, Jangan Lompat

Gunakan satu akun Google yang sama selama proses setup supaya permission, Google Sheets, dan Apps Script tidak tercampur.

01

Buka Member Area Whitelabel Membership

Di Member Area, cari file bernama “Whitelabel Membership GAS Client”. Klik tombol Copy / Salin File agar Anda mendapatkan salinan Google Sheets milik Anda sendiri.

✓ Jangan bekerja langsung dari file master
02

Buat Salinan Google Sheets ke Akun Anda

Setelah halaman Google Sheets terbuka, konfirmasi proses Make a copy / Buat salinan. Simpan di Google Drive Anda dan beri nama yang mudah dikenali.

  • Contoh nama: Whitelabel Membership GAS - Brand Saya.
  • Pastikan file hasil copy dapat Anda edit.
  • Jika menu custom belum muncul, tunggu beberapa saat lalu refresh halaman.
03

Klik Menu “Whitelabel System”

Pada toolbar Google Sheets, klik menu Whitelabel System. Jalankan proses setup / instalasi yang tersedia pada menu tersebut sampai sistem selesai menyiapkan file Anda.

  • Jika Google meminta izin akses, lanjutkan proses authorization menggunakan akun Google Anda sendiri.
  • Jangan tutup file selama proses setup masih berjalan.
✓ Menu ini terlihat di toolbar seperti contoh gambar di atas
04

Buka Apps Script dan Deploy sebagai Web App

Setelah setup selesai, buka project Google Apps Script yang terhubung dengan Google Sheets tersebut, lalu buat deployment Web App.

  • Klik Deploy → New deployment.
  • Pilih tipe Web app.
  • Jalankan sebagai akun Anda.
  • Set akses Web App agar dapat dipanggil oleh frontend sesuai pengaturan aplikasi.
  • Klik Deploy dan selesaikan permission jika diminta.
05

Copy URL Hasil Deploy

Setelah deployment berhasil, Google akan memberikan Web App URL. Copy URL tersebut. URL inilah yang menghubungkan frontend HTML dengan Google Sheets + Apps Script Anda.

Contoh bentuk URL Web App
https://script.google.com/macros/s/XXXXXXXXXXXX/exec
Jangan gunakan URL editor Apps Script.

Yang dipasang ke frontend adalah URL hasil Deploy Web App yang biasanya berakhiran /exec.

06

Pasang URL Deploy ke file index.html

Buka file frontend index.html. Cari bagian URL backend Google Apps Script, lalu ganti URL lama / URL contoh dengan Web App URL yang baru Anda deploy.

index.html
// MASUKIN URL WEB APP GAS LO DI SINI
const API_URL = "https://script.google.com/macros/s/URL-DEPLOY-ANDA/exec";

Pada versi frontend yang digunakan untuk Whitelabel Membership, koneksi dashboard memakai konstanta API_URL. Pastikan tidak ada tanda kutip yang terhapus.

07

Pasang URL yang Sama ke checkout.html

Buka file checkout.html lalu cari bagian URL backend / Apps Script. Ganti dengan Web App URL yang sama seperti yang Anda pasang di index.html.

checkout.html
const API_URL = "https://script.google.com/macros/s/URL-DEPLOY-ANDA/exec";
Satu backend, satu URL yang sama.

Dashboard dan checkout harus mengarah ke deployment Apps Script dari Google Sheets client milik Anda, bukan ke deployment demo atau milik orang lain.

08

Simpan Frontend, Buka, dan Uji sampai Checkout

Setelah URL pada index.html dan checkout.html sudah benar, simpan file frontend lalu jalankan pada lokasi publik yang Anda gunakan.

  • Login ke dashboard.
  • Cek produk dan member.
  • Cek link affiliate.
  • Buka link checkout produk.
  • Lakukan transaksi uji coba.
  • Pastikan transaksi masuk ke sistem dan data terbaca dengan benar.
✓ Kalau seluruh alur berjalan, sistem siap live
