Urutan Setup yang Direkomendasikan

Ikuti alur ini agar frontend berhasil terhubung dengan backend Google Apps Script Anda sendiri.

01 Salin Google Sheets Buat copy template database ke akun Google Anda.
02 Cek Apps Script Buka Extensions → Apps Script dan pahami file code.gs.
03 Deploy Web App Deploy sebagai Web App dan simpan URL deployment Anda.
04 Pasang SCRIPT_URL Ganti URL backend di seluruh file HTML yang membutuhkan koneksi.
05 Hosting & Tes Upload frontend, lalu tes login, produk, checkout, email, dan pembayaran.
⚠ Catatan Super Penting

Wajib Ubah URL Web App Google Apps Script di Frontend!

Frontend tidak akan bekerja dengan database Anda sendiri sebelum URL Web App Apps Script diganti dengan URL deployment milik Anda.

const SCRIPT_URL = 'MASUKKAN_URL_WEB_APP_GOOGLE_APPS_SCRIPT_ANDA_DI_SINI';
⚠ Cari variabel seperti SCRIPT_URL, API_URL, atau endpoint Apps Script pada file HTML yang terhubung ke backend.
⚠ Pastikan URL berasal dari deployment Web App milik akun Google Anda sendiri.
⚠ Setelah mengganti URL, tes kembali login, pengambilan produk, transaksi, checkout, dan fungsi notifikasi.
