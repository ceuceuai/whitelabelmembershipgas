FAQ

Pertanyaan yang Sering Diajukan

Apakah ini jalan di hosting cPanel/VPS?
Tidak. Ini adalah source code berbasis Google Apps Script (GAS). Database menggunakan ekosistem Google dan file dijalankan dari sana. Anda tidak membutuhkan cPanel, VPS, atau hosting berbayar konvensional.
Maksud dari "Wajib Rebrand" itu apa?
Anda tidak diperbolehkan menjual kembali produk ini menggunakan nama "Whitelabel Membership", warna utama, logo, atau copy yang sama persis dengan halaman penjualan kami. Anda wajib mengubahnya dengan identitas brand Anda sendiri agar memiliki nilai jual berbeda.
Apakah ada integrasi Payment Gateway otomatis?
Tidak ada. Sistem bawaan dirancang simpel menggunakan metode Transfer Manual dan QRIS Statis. Jika Anda paham koding, Anda tentu bebas mengembangkan dan mengintegrasikannya sendiri dengan layanan pihak ketiga.
Apakah dapat update gratis?
Produk ini dijual secara "As Is" (sebagaimana adanya) sebagai source code pondasi. Karena Anda akan banyak mengubah kodenya, kami tidak menyediakan sistem update otomatis.
Apakah bisa Refund jika tidak mengerti koding?
Tidak. Semua penjualan bersifat final (No Refund) mengingat sifat produk ini adalah source code digital yang dapat disalin. Silakan baca rules dan coba demo admin secara menyeluruh sebelum melakukan pembelian.
